# COMSATS Merit Lists & Aggregate Calculator

This web app has the merit lists for every program at COMSATS University Islamabad, plus a merit calculator that students can use to work out their aggregate.

## Features

- Merit lists for Spring 2020–22 and Fall 2019–22 intakes (`sp20.html` … `f_22.html`)
- Aggregate calculator (`calculator.html`)

## Tech stack

HTML · CSS · JavaScript (`index.php` simply serves `index.html` on PHP hosting)

## Running

Open `index.html` in a browser.
